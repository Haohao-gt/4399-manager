## 项目介绍

一个**本地运行**的 Windows 桌面程序：界面是 Electron 窗口（和 QQ 同一套技术），业务逻辑跑在程序自带的本地 Node 服务里，数据全程不出本机。

**下载解压，双击 `4399账号管理器.exe` 就能用** —— 不用装 Node.js，不用装运行库，不写注册表。

只用于管理**你自己的** 4399 账号。登录态与账号数据全部保存在程序目录的 `data/` 里，本地服务只监听 `127.0.0.1`，同一局域网内其它设备也访问不到。

核心能力：

- **多账号集中管理**：登录态、昵称、UID、头像、积分、等级、成长值、性别、地区、IP 属地、认证状态一屏看完
- **一键签到**：群组首页签到 + 独家游戏签到，支持批量
- **本地账号库**：账号密码以 **AES-256-GCM 加密**落盘，支持批量登录，不用一个个手输
- **区服角色查询**：按游戏缩写查询各区服下的角色，内置常用游戏预设
- **资料修改 / 换头像**：昵称、性别、生日、地区，以及本地上传头像
- **三套深色主题**：4399 石墨橙、小林家的龙女仆、梵高「星空」一键切换
- **较长的任务可取消**：区服查询、实名查询走任务队列，随时中断，中间结果保留

## 项目实现方式

整个项目是**手写**的，没有用任何框架、脚手架或 npm 包，只依赖 Node.js 内置模块。

| 层 | 实现方式 |
|---|---|
| **后端** | Node.js 原生 `http` / `fs` / `path` / `child_process` / `crypto`，单文件 `server.js` + `lib/`，无构建步骤 |
| **前端** | 原生 HTML + CSS + ES2020 JavaScript，无框架、无打包器，静态文件直接由后端服务 |
| **桌面壳** | `public/ntqq.css` 覆盖层 + `public/shell.js`，把原页面包进「标题栏 / 图标栏 / 会话列表 / 内容区」四段式；不侵入原有页面逻辑，只在 `renderAccounts()` 末尾同步一次会话列表 |
| **桌面版** | `desktop/` 下的 Electron 外壳：无边框窗口 + `preload.js` 只暴露窗口控制；服务端用 `ELECTRON_RUN_AS_NODE` 子进程托管，端口被占用时自动复用或顺延 |
| **登录协议** | 走 4399 网页 OAuth（`ptlogin.4399.com/oauth2/authorize.do` → `loginAndAuthorize.do`），手写 CookieJar 维护会话 |
| **网络层** | 自实现极简 HTTP 客户端（重定向跟随、multipart 上传、指数退避重试）；登录类请求不重试，避免重复提交 |
| **数据存储** | 本地 JSON 文件（`data/`）。账号登录态明文保存，账号密码用 **AES-256-GCM** 加密，单密钥 + 每行随机 IV |
| **长任务** | 服务端 Job 表 + 前端约 320ms 轮询，提供 `/api/jobs/:id` 与 `/cancel`，取消后仍返回已完成的中间结果 |
| **并发与限流** | 区服查询采用「波浪并发」：初始并发 3，一旦命中 4399 限流自动降到 1 并退避；批量刷新整波失败则转串行 |
| **风控识别** | 识别 4399 限流 / 静默风控特征，命中后自动停机并 30 秒 × 2 次退避，不做绕过 |
| **验证码** | 64 位 Node 无法加载 32 位 OCR 模型，因此用 `tools/ocrbridge.exe` 做子进程桥（源码 `tools/OcrBridge.cs`）；识别失败自动退回手动输入 |
| **主题系统** | 纯 CSS 自定义属性 + `html.theme-*` 类切换，三套配色互不干扰，无 JS 重绘 |
| **图标** | 内联 SVG 路径表（`ICONS` map），不用图标字体、不用 Emoji |
| **宣传片** | Canvas 2D 逐帧绘制动画，`MediaRecorder` 录制 1920×1080 视频并回传本地保存（`public/promo-studio.html`） |

## 快速开始（解压即用）

**下载 → 解压 → 双击 exe**，就这三步：

1. 打开 [最新版本 Releases](https://github.com/Haohao-gt/4399-manager/releases/latest)
2. 下载 **`4399-manager-x.x.x-win64.zip`**（约 140 MB）
3. 解压到任意目录，比如 `D:\4399账号管理器`
4. 双击文件夹里的 **`4399账号管理器.exe`**

不安装、不写注册表、不装 Node.js。不想要了直接删文件夹。

### 文件夹长什么样

和 QQ 的安装目录一个道理：一堆运行时文件，中间那个 exe 才是本体。

```
4399账号管理器\
├─ 4399账号管理器.exe          ← 双击这个
├─ chrome_100_percent.pak
├─ icudtl.dat
├─ vk_swiftshader.dll
├─ resources\
│  ├─ app.asar                  （外壳：窗口 / 托盘 / 窗口按钮）
│  └─ app\                      （server.js · lib · public · tools）
├─ data\                        （第一次运行自动创建：账号数据）
└─ ...
```

### 数据放哪

**就在 exe 旁边的 `data\` 文件夹**，第一次运行自动创建。换电脑直接把整个文件夹拷走，账号、分组、本地账号库、密钥全都跟着走。

> 如果解压到 `C:\Program Files` 这种没有写权限的位置，数据会自动改存到 `%APPDATA%\4399账号管理器\data`。

### 这个桌面版有什么

- **无边框窗口 + 自绘标题栏**：右上角 最小化 / 最大化 / 关闭 是真的窗口按钮
- **关窗口 = 收进托盘**，托盘图标右键「退出」才真退；窗口位置大小会记住
- **不需要装 Node.js**：Electron 自带运行时，双击即用
- **启动 1~2 秒**：解压版直接从文件夹加载，没有单文件版那种「先解包到临时目录」的等待
- 外链一律用系统默认浏览器打开

## 新手详细教程（电脑小白专用）

> 下面这套流程假设你**从没装过 Node.js、没用过命令行**，全程只需要鼠标点，不用敲代码。

### 第 1 步 · 下载压缩包

1. 打开项目主页 <https://github.com/Haohao-gt/4399-manager>
2. 点右侧的 **Releases**，或直接打开 [最新版本](https://github.com/Haohao-gt/4399-manager/releases/latest)
3. 在 **Assets** 里点 **`4399-manager-x.x.x-win64.zip`** 下载（约 140 MB）

### 第 2 步 · 解压

1. 找到下载好的 zip，**右键 → 全部解压**（Windows 11 显示为「全部解压…」）
2. 建议解压到简单路径，比如 `D:\4399账号管理器`
3. 打开文件夹，应该能直接看到 **`4399账号管理器.exe`** 和一堆 `.dll`、`.pak` 文件

> **不要在压缩包里直接双击运行**，必须先解压出来。
>
> 解压后如果多套了一层同名文件夹，进到有 `4399账号管理器.exe` 的那一层就对了。

### 第 3 步 · 双击打开

1. 双击 **`4399账号管理器.exe`**
2. 如果弹出蓝色的「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**（这个包没买代码签名证书，属正常现象）
3. 等 1~2 秒，窗口出来
4. 右上角是最小化 / 最大化 / 关闭；**点关闭会收进右下角托盘**，右键托盘图标选「退出」才是真退出

**想卸载**：直接删掉整个文件夹即可（账号数据也在里面，想留着就先拷走 `data` 文件夹）。

### 第 4 步 · 登录第一个账号

1. 点左侧导航栏的 **「添加账号」**
2. 在弹窗里输入 4399 的**账号**和**密码**
3. 出现图形验证码时照着图输入（配好 OCR 后大部分会自动识别）
4. 点登录
5. 成功后账号卡片会出现在「账号总览」首页

重复这个操作，就能把所有账号都加进来。

### 第 5 步 · 批量管理（可选）

- **批量导入账号密码**：点左侧「本地账号库」，把 `账号 密码` 每行一组粘贴进去，或者导入 txt
- **批量登录**：在本地账号库里勾选若干条，点「批量登录」
- **批量签到 / 刷新**：在账号总览勾选账号，用上方的批量按钮
- 批量操作**会限速**，遇到 4399 风控会自动停下来，这是正常保护，不是坏了

### 更新到新版本

- **用 ZIP 下载的**：重新下载新版并解压，把**旧文件夹里的 `data` 整个复制到新文件夹**，再删掉旧文件夹
- **用 Git 的**：在项目文件夹里执行 `git pull`

> **最重要的一句话**：`data` 文件夹里是你的登录态和本地账号库。**更新前一定先备份**，千万别直接覆盖删掉！

### 卸载 / 彻底清除

1. 关掉黑色窗口
2. 想留个底的话，先在「设置 → 数据」里点「导出备份」
3. 想彻底不留痕迹：在「设置 → 数据」里点「清除全部数据」（会删掉登录态、密码、密钥、缓存、日志）
4. 最后把整个文件夹删掉即可

### 常见问题

<details>
<summary><b>双击 bat，黑窗口一闪就没了</b></summary>

多半是 Node.js 没装好。按 `Win + R` → `cmd` → 输入 `node -v` 检查；没有版本号就回去重装 Node.js，装完**重启电脑**再试。
</details>

<details>
<summary><b>提示「Windows 已保护你的电脑」</b></summary>

这是 Windows 对从网上下载的脚本的常规拦截。点「更多信息」→「仍要运行」即可。
</details>

<details>
<summary><b>杀毒软件拦截 / 报毒</b></summary>

火绒、360、Windows Defender 有可能拦截 `tools/ocrbridge.exe`（它是加载验证码识别模型的子进程桥）。这属于误报，加入信任 / 白名单即可，不影响其它功能。
</details>

<details>
<summary><b>双击后没反应 / 窗口一闪就没了</b></summary>

- 先看右下角托盘里有没有图标（关闭窗口只是收进托盘，程序还在跑）
- 端口 8790 被占用时程序会自动换端口，一般不用管；想排查可以按 `Win + R` → `cmd` → `netstat -ano | findstr :8790`
- 火绒 / 360 有可能拦住 `tools/ocrbridge.exe`，加白名单后重启程序
</details>

<details>
<summary><b>登录一直提示验证码错误 / 登录失败</b></summary>

- 点验证码图片可以刷新，换一张再试
- 4399 有时会临时限流，等 5~10 分钟再试
- 确认账号密码没输错（注意大小写）
</details>

<details>
<summary><b>签到 / 刷新失败</b></summary>

基本都是登录态过期了。在账号卡片上点「重新登录」，重走一遍登录流程即可。
</details>

<details>
<summary><b>数据存在哪？怎么备份？</b></summary>

- 所有数据都在项目文件夹的 `data` 目录里
- 推荐用「设置 → 数据 → 导出备份」生成备份文件
- 也可以直接把整个 `data` 文件夹复制走
- **注意**：备份文件里**不包含** `data/vault.key`，换电脑恢复后本地账号库的密码需要重新登录写入一次
</details>

<details>
<summary><b>换电脑怎么迁移？</b></summary>

1. 新电脑解压一份同样的绿色版
2. 把旧电脑程序目录里的 `data` 整个文件夹拷到新电脑同一位置（覆盖）
3. 双击 exe 即可

想保留本地账号库里的密码，一定要确保 `data/vault.key` 一起拷过去。
</details>

<details>
<summary><b>用这个会不会被封号？</b></summary>

本工具只对**你自己的账号**做登录、签到、查询这类正常操作，不做撞库、不刷数据。批量操作内置限速，遇到风控会自动停止。但请**不要高频批量操作**，账号安全风险由使用者自行承担。
</details>

## 数据与安全

| 文件 | 内容 |
|---|---|
| `data/accounts.json` | 账号登录态（**含 cookie**，请勿外传） |
| `data/vault.json` | 本地账号库（密码为 AES-256-GCM 密文） |
| `data/vault.key` | 解密密钥（**32 字节，永不外传**） |
| `data/folders.json` | 分组 |
| `data/config.json` | 配置 |
| `data/music-cache.json` / `data/music-covers/` | 音乐组件缓存 |
| `data/errors.log` | 错误日志 |

- 加密格式：`enc:v1:<base64(iv[12] | tag[16] | ciphertext)>`，无该前缀的按历史明文处理
- **备份文件不含 `data/vault.key`**：换机恢复后，本地账号库里原有的密码将无法解密，重新登录一次即可重新写入
- `data/` 已整体加入 `.gitignore`，不会被提交

## 已知限制

- 区服角色查询接口只对少数游戏开放，内置 6 个实测可用；其它游戏会提示无法解析
- 每个区服查询约需 3 秒（服务端限流），请按需勾选
- 4399 接口可能随时调整；若登录或签到失效，需要更新 `lib/4399.js`
- 实名查询按钮需要先在「设置 → 辅助账号」配置好辅助账号
- 修改资料仅支持昵称 / 性别 / 生日 / 地区，**不含** QQ / 邮箱
- 验证码 OCR 为自训练模型，不是 100% 准确，失败时退回手动输入
- 宣传片录制依赖 `MediaRecorder`，录制时标签页必须保持前台
- 若某账号 cookie 失效（签到 / 刷新失败），重新登录一次即可
